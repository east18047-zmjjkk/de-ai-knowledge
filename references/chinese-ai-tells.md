# Chinese AI Writing Tells — Knowledge Reference

常见中文 AI 写作痕迹。用于诊断和改写参考。基于公开语料观察与实践总结，非严格频率统计。

## 高优先级词汇与短语

| 痕迹 | 说明 | 建议 |
|------|------|------|
| 不是A而是B / 不在于A而在于B | 翻案腔，连续出现为模板 | 直接说重点 |
| 众所周知 / 显而易见 / 值得注意的是 | 空转开场 | 删除或直接陈述 |
| 赋能 / 助力 / 深耕 / 打造 / 构建 | 商务/分析腔堆叠 | 换成具体动作 |
| 说白了 / 本质上 / 归根结底 / 简单来说 | 单次可接受，连用为讲义腔 | 控制频率 |
| 随着……的发展 / 在当今……时代 | 套路开头 | 删除或具体化 |
| 综上所述 / 总之 / 总而言之 | 教科书收尾 | 自然结束 |
| 揭开真面目 / 戳穿真相 / 遮羞布 | 戏剧化揭露 | 删除或具体描述 |

## 结构与句式

- 段首零主语评论（直接下判断无回指）
- 序数词小标题过多（一、二、三密集）
- 冒号当提纲路标（“原因：”“关键在于：”）
- 顿号罗列过密
- 相邻句结构同款（排比式工整）
- 空转句 + 冒号 + 列表
- 每段都有“更关键/更要命/换句话说”等路标词

## 原则

- 瞄准人类写作区间，不是 AI 的反面。偶尔路标词、偶尔对比是正常的。
- 信息守恒：不新增事实，不删除核心论证。
- 单次自然出现不强制修改；成簇、连段才处理。
- 正式语体在正式场合可保留，不必强行口语化。

## 误判注意

干净语法、单次破折号/冒号、作者习惯用词、引文对话，本身不是 AI 证据。
